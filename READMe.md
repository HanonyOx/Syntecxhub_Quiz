# Quiz App 🎯

A simple and interactive **Quiz App** built with **HTML, CSS, and JavaScript**. The application presents multiple-choice questions, allows users to submit their answers, and provides immediate feedback based on their selection.

This project was developed as part of my **Syntecxhub Internship** to practice and demonstrate my understanding of JavaScript fundamentals, DOM manipulation, event handling, and interactive web development.

## 🚀 Features

* Randomly displays quiz questions.
* Multiple-choice answers for each question.
* Allows users to submit their selected answer.
* Shows visual feedback for correct and incorrect answers.
* Displays the correct answer when an incorrect option is selected.
* Alerts the user when no option has been selected.
* Automatically moves to another question after answering.
* Responsive and simple user interface.

## 🛠️ Technologies Used

* **HTML5** – Used to structure the application.
* **CSS3** – Used for styling and layout.
* **JavaScript** – Used to handle the quiz logic, user interactions, question selection, and DOM manipulation.

## ⚙️ How It Works

The quiz questions are stored in an array of objects. Each question contains:

* The question itself
* Four possible options
* The correct answer

When the application loads, a question is randomly selected and displayed. When the user submits an answer, JavaScript checks the selected option against the correct answer and provides visual feedback.

If the answer is incorrect, the correct answer is displayed before the application moves to another question.
